# RefuteGate Test Research Project

This repository contains non-sensitive example research artifacts used for
end-to-end validation of RefuteGate.

The `sample-study` fixture deliberately contains claim/evaluation mismatches so
that a real reviewer has substantive issues to detect. It tests the review
protocol; it is not a real scientific result or unpublished research.

Do not upload unpublished, licensed, personal, or otherwise sensitive data while
this repository is public.
